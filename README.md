# Exercice physique chimie 3AC

Application d'exercices de physique-chimie pour la 3ème année collège (3AC) :
17 leçons, 850 questions, entraînement libre et quiz notés (classes 3AC1 à 3AC5).

Adresse du site : https://redabirharassen.github.io/exercice-pc-3ac/

## Fichiers
- `index.html` : l'application complète
- `jspdf.umd.min.js` : bibliothèque pour créer les PDF des comptes élèves
- `confidentialite.html` : politique de confidentialité
- `.nojekyll` : indique à GitHub Pages de publier les fichiers tels quels
